# 🛒 Каталог товаров на SQLite + Python

## 📌 Описание

Простой Python-скрипт, который:

* создаёт базу данных товаров,
* вставляет случайные и ручные товары,
* индексирует таблицу,
* делает выборки по товарам без описания и дешевле 10,000,
* создаёт представление с фильтрацией и сортировкой.

Используется: **SQLite** (через `sqlite3`) и **стандартная библиотека Python**.

---

## 🚀 Как запустить

1. Установите Python 3.8+
2. Скачайте или клонируйте репозиторий
3. Запустите скрипт:

```bash
python main.py
```

## 📋 Функционал

* ✅ Создание таблицы `items` (если не существует)
* ✅ Вставка одного ручного и 10 случайных товаров
* ✅ Индексация по `art`, `price`, `description`
* ✅ Вывод:

  * всех товаров
  * товаров без описания
  * товаров с ценой < 10,000
* ✅ Создание представления `items_below_10000` с сортировкой по возрастанию
